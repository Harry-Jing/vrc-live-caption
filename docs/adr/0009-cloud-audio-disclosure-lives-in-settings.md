# Cloud audio disclosure lives in Settings

Date: 2026-07

A persistent line in the cloud-recognition section of Settings states that microphone
audio is uploaded to OpenAI for transcription. A startup confirmation dialog
and a banner on the main page were considered and rejected to keep the
primary interface clean; the disclosure stays visible whenever an OpenAI cloud
recognition path is selected.

Revisit if users report they did not understand audio was uploaded, or a
distribution channel requires stricter compliance.
